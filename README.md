# すたんぷポケット

きぐるみっこと一緒に、スタンプの仕上げを。
一覧画像の切り抜き・背景透過・お直し・キープ・ZIP保存を、スマホやパソコンのブラウザで行えるツールです。

## 使い方

1. 作りたいセットの枚数を選びます。
2. 画像を入れ、行・列と切り抜き線を確認します。
3. 仕上がりの良いものだけキープします。別の画像からも追加できます。
4. 白や淡い色が透けたら「お直し」で控えめな透過や台紙の復元を試します。
5. 枚数がそろったら、確認してZIPを保存します。

## 保存について

画像処理はブラウザ内で行います。アプリは入力画像をサーバーへアップロードしません。
キープと作業途中の画像は、使っている端末・ブラウザの保存領域に保存します。「自動保存しました」を確認してから閉じてください。
ブラウザの保存データを削除した場合や、別の端末・別のURLでは同じストックを開けません。端末間同期はありません。

## 対応範囲

通常の静止画スタンプ（8・16・24・32・40個）。PNG・JPEG・WebPの一覧画像や個別画像を読み込めます。
背景透過は単色背景向けです。元画像と同じ白の台紙は範囲を指定して復元できます。
画質補正は補間による2倍拡大と輪郭補正です。AIによる細部の復元は行いません。
LINEへの申請はこのツールからは行いません。LINE非公式の画像準備ツールです。
スマホ向け画面を用意していますが、端末・ブラウザによって保存やダウンロードの挙動が異なります。

Settings → Pages → Deploy from a branch → main / (root) → Save で公開できます。

## 開発
