# すたんぷポケット

きぐるみっこと一緒に、スタンプの仕上げを。
透過済み画像の切り分け・位置調整・キープ・スライド並べ替え・ZIP保存を、スマホやパソコンのブラウザで行えるツールです。

## 使い方

1. LINEスタンプかLINE絵文字を選び、作りたいセットの枚数を選びます。
2. 画像を入れ、行・列と切り抜き線を確認します。
3. 切り抜いた画像を確認し、残したいものだけ選んでストックへ追加します。追加前に位置や大きさも調整できます。
4. ストックから仕上がりの良いものをキープします。別の画像からも追加できます。
5. 枚数がそろったら、確認してZIPまたは個別PNGで保存します。

## 保存について

画像処理はブラウザ内で行います。アプリは入力画像をサーバーへアップロードしません。
キープと作業途中の画像は、使っている端末・ブラウザの保存領域に保存します。「自動保存しました」を確認してから閉じてください。
ブラウザの保存データを削除した場合や、別の端末・別のURLでは同じストックを開けません。端末間同期はありません。

## 対応範囲

通常の静止画スタンプ（8・16・24・32・40個）と静止画絵文字（8〜40個）。PNG・JPEG・WebPの一覧画像や個別画像を読み込めます。
背景は自動で透過しません。きれいに透過したPNGを用意してから読み込んでください。
画質補正は補間による2倍拡大と輪郭補正です。AIによる細部の復元は行いません。
LINEへの申請はこのツールからは行いません。LINE非公式の画像準備ツールです。
スマホ向け画面を用意していますが、端末・ブラウザによって保存やダウンロードの挙動が異なります。

## 開発

source-code.zipにアプリのソースが入っています。展開してNode.js 24以降で npm install、npm run build を実行します。

## スタンプ・絵文字の切り替え

最初の画面で「LINEスタンプ」または「LINE絵文字」を選びます。通常の静止画に対応しています。キープ画像は共通で、種類を変えても残ります。

| 種類 | 本体 | 枚数 | メイン | タブ | ZIP上限 |
| --- | --- | --- | --- | --- | --- |
| LINEスタンプ | 370×320px | 8・16・24・32・40 | 240×240px | 96×74px | 60MB |
| LINE絵文字 | 180×180px | 8〜40の任意の整数 | 別ファイル不要 | 96×74px | 20MB |

スタンプは01.pngから、絵文字は001.pngから連番で出力します。PNGは1枚1MB以下。スタンプは余白をつけ、絵文字は縦横比を保ってキャンバスいっぱいに配置します。小さい元画像は絵文字サイズに合わせて拡大されるため、保存前に画質を確認してください。
絵文字の個数からスタンプへ切り替えるときは、対応する次の枚数へ調整します（例：9個→16個）。
